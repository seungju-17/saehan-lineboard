# 새한프라텍 인원 배치 · 결원 대체 (평가용 MVP)

앱 이름은 「새한프라텍」입니다. (옛 이름 라인보드)

하루 한 장의 배치표를 그대로 화면에 옮긴 도구입니다.
이전 표가 자동으로 복사되고(조가 바뀌는 날은 같은 조가 마지막으로 그 근무를 한 날의 표), 결원이 생기면 경험 순으로 고른 3명에게 대체 요청이 나갑니다.
제품이 적혀 있는데 근무자가 없는 라인은 자동으로 빨갛게 표시됩니다.

## 실행

```bash
npm install
npm run seed   # data/lineboard.db 생성 (직원 명단 + 2025년 8·9·11월 1공장, 8~12월 2공장 실제 배치표를 날짜 그대로 이력으로)
npm run dev    # http://localhost:3000  비밀번호: saehan
```

Node 20 이상. pnpm이 있으면 `pnpm install / pnpm seed / pnpm dev`도 됩니다.
Windows PowerShell에서 `npm`이 보안 정책으로 막히면 `npm.cmd`로 입력하세요.
외부 서비스·DB 설치 없음 (SQLite 파일 하나).

체험판(docs/index.html)의 「누구로 들어갈까요」에서 근무자는 목록에서 고르거나, 자기 이름을 끝까지 정확히 치고 Enter를 눌러 들어갑니다. 이름 일부나 초성으로는 찾지 않습니다.

**운영 구조 반영** (docs/운영구조_분석_2025.md 참고)
- 2공장 프리폼 P라인은 무인: 제품만 적고 사람은 없어도 정상.
- 라인 코드를 누르면 「라인 부동(세움)」: 결원 때 라인 하나를 세우고 인원을 옮기는 현장 방식. 부동 라인은 빈 자리로 치지 않음.
- 이름을 누르면 근태: 결근(자리 비움 + 대체 요청) · 연차·병가(자리만 비움) · 반차·지각·조퇴·교육(기록만).
- 표 위에 남/여 인원, 다른 공장 소속이면 이름 옆에 「n공장」, 비고 한 줄.
- 두 공장 모두 「입안 → 마지막 단계」 두 단계. 반장이 입안하면 1공장은 팀장·담당자가 「확정」, 2공장은 결재 문서라 팀장만 「결정」하고 인쇄에 결재란.
- 「월 근태표」: 회사 양식(집단별 시트, 사람당 두 줄, 직영 11일~익월 10일 / 협력사 1일~말일)으로 엑셀 내려받기.
- 토·일은 지난 휴일 표를 기준으로 복사.
- 직원 명단에 2025-09·2025-11 근태표 명단(집단·소속·조·성별) 반영. 11월 명단이 더 새것이라 겹치면 11월을 따릅니다.
- 조 달력 기준일은 2025-11-01입니다. 1공장 2025년 11월 배치표에서 C조 주간 1일째·A조 야간 3일째·B조 휴무 1일째로 확인했고, 8~10월 표와 맞춰 보면 1공장 93~94%, 2공장 73%가 이 달력과 일치합니다. 자료는 날짜를 옮기지 않고 2025년 그대로 넣습니다. 체험판은 자료가 끝난 다음 날인 2025-12-01을 「오늘」로 보며(빌드 때 `demo/dist/demo.db`를 따로 시드), 설치판은 실제 오늘 날짜로 돌고 2025년 자료는 과거 이력이 됩니다.
- 데이터 파일: `data/f1_assignments.csv`(1공장 8·9월), `data/f1_assignments_2025_11.csv`(1공장 11월), `data/f2_assignments.csv`(2공장 8~12월), `data/roster_2025_09.csv`·`data/roster_2025_11.csv`(근태표 명단), `data/people_seed.csv`.

**자동 채우기**: 제품이 적힌 라인마다 과거 표에서 보통 몇 명이 섰는지 세어, 모자란 만큼 후보 순위대로 넣습니다. 자동으로 들어간 이름은 연한 남색. 확인하고 고친 뒤 확정합니다.

**관리자와 근무자**: 한 앱에 관리자 화면과 근무자 화면이 있습니다. 관리자는 아이디·비밀번호로 들어가며 역할이 셋입니다. 팀장(전부, 2공장 「결정」), 담당자(2공장 결정만 빼고 전부, 1공장 「확정」), 반장(배치·현황·대체 요청, 「입안」까지). 입안된 표는 알림함에 「입안」으로 쌓입니다. 기본 계정은 teamlead · staff · lead1 · lead2, 비밀번호는 LINEBOARD_PASSWORD(기본 saehan)입니다. 근무자는 폰에서 전화번호를 넣고 문자로 온 인증번호로 한 번 들어오면 유지됩니다(체험판 인증번호 1234). 근무자 화면은 「내 근무」(오늘·이번 주·근무시간), 「요청」(대체 요청 수락·거절), 「근태」, 「알림」 네 탭입니다. 알림은 앱 알림함에 쌓이고 전화번호가 있으면 문자로도 갑니다(도입 때 문자 발송 연결).

**휴가 신청과 알림함**: 근무자는 폰 「근태」 탭에서 연차·반차·병가를 신청합니다. 담당자·팀장은 왼쪽 메뉴 「알림」에서 승인·거절(한 줄 답 가능)합니다. 승인하면 그날 표에서 그 사람 자리를 비우고 연차·병가는 대체 요청까지 자동으로 나가며, 반차는 기록만 남습니다. 알림함 아래에는 최근 7일의 수락·거절·신청 내역이 쌓이고, 메뉴에 처리할 신청 수가 빨간 숫자로 보입니다. 근무자 폰의 근태 탭에는 달력(근무일은 주·야 표시, 결근 빨강, 지각 주황, 연차 파랑, 병가 초록)이 있고, 지난 1년치를 달마다 넘겨 볼 수 있습니다. 달 머리에 그달 근무 일수(주간·야간)가 나오고, 달력 아래 「달별 근무 시간」 표에 달마다 주간·야간·합계 시간(한 교대 시간 × 일수)이 나옵니다. 체험판은 2025년 8~11월 기록이 그대로 보입니다.

**입안 뒤 수정**: 입안한 표의 배치 내용(제품·인원·사람·부동·비고·자동 채우기)을 고치면 결재 대상이 바뀐 것이므로 자동으로 초안으로 돌아가고 표 머리에 「입안 취소됨」이 보입니다. 다시 입안하면 됩니다. 당일 근태 처리와 대체 요청은 입안을 유지합니다.

**후보 없음**: 결근 처리나 「후보에게 요청」에서 보낼 사람이 없으면 그 자리 말풍선에 「후보 없음」과 「직접 넣기 (이름 검색)」이 뜹니다. 자동 채우기는 못 채운 라인을 결과에 같이 보여 줍니다(「못 채운 라인: S-4 1명」).

**라인 표시**: 배치표는 엑셀 양식의 모든 라인(1공장 34줄, 2공장 16줄)을 늘 보여 줍니다. 위 버튼 줄의 「쉬는 라인 접기」를 켜면 그날 안 돌리는 라인(제품도 사람도 없는 라인)은 숨기고 구역 머리에 「쉬는 라인 n개 접힘」만 남습니다. 선택은 브라우저에 기억됩니다.

**날짜 고르기**: 표 머리의 날짜를 누르면 달력이 뜨고, 달력 머리의 「○년 ○월」을 누르면 연도(‹ ›)와 달(12칸)을 바로 고를 수 있습니다.

**공유 링크**: 주소의 `?date=…&shift=…&factory=…` 를 서버판·체험판 모두 읽어 그 표를 엽니다. 체험판 예: `index.html?date=2026-11-03&shift=야간&factory=2#today`.

**반려**: 반장이 「입안」한 표를 팀장(1공장은 담당자도)이 「반려」(사유 한 줄)하면 초안으로 돌아가고 표 머리에 사유가 보입니다. 작성자가 고쳐 다시 입안하면 사유는 지워집니다.

**직원 이번 주 시간**: 직원 화면 오른쪽 열에 이번 주 근무시간이 있고, 한 교대를 더하면 주 최대 시간을 넘는 사람은 주황 「한도」 표시가 붙습니다.

**필요 인원**: 라인마다 필요 인원이 있습니다. 기본값은 복사해 온 표의 인원이고, 제품을 바꾸면 그 제품으로 섰던 날의 인원을 제안하며, 인원 칸을 눌러 직접 바꿉니다. 「빼기」로 일부러 빼면 필요 인원이 남은 인원으로 내려가고, 「+」로 더 넣으면 올라갑니다. 결근·병가로 빠진 건 필요 인원을 유지합니다. 「빼기」로 마지막 한 명까지 빼면 오늘 안 돌리는 라인으로 보고 자동으로 부동 처리합니다(라인 번호 → 부동 해제로 되돌림). 다음 날 표에는 지난 표에서 실제로 돌린 라인의 제품만 복사되고, 안 돌린 라인은 엑셀처럼 빈 줄로 시작합니다. 제품은 최근 표에서, 사람은 같은 조가 섰던 표에서 오기 때문에 사람이 복사되지 않은 라인은 제품도 비웁니다. 그래서 표를 처음 열면 빈 자리가 없고, 결근 처리를 해야 생깁니다. 「비어 있음」은 있는 사람이 필요 인원보다 적을 때만 뜨고 「비어 있음 1/2」처럼 보입니다. 2명 라인에서 1명이 결근해도 남은 인원으로 충분하면 「요청 보내기 / 기록만」을 고릅니다.

**근태와 대체 요청**: 결근·연차·병가는 자리를 비우고 바로 후보 3명에게 요청합니다. 반차·조퇴·교육은 표시할 때 「요청 보내기 / 기록만」을 고릅니다. 지각은 기록만 합니다. 어느 쪽이든 월 근태표에는 사유가 그대로 남습니다.

**후보 규칙과 설정**: 후보는 오늘 쉬는 조 → 그 라인 경험 → 같은 제품 → 최근 30일 대체 횟수(감점) 순입니다. 오늘 결근·연차·병가인 사람은 제외하고, 이번 주(월~일) 근무시간에 한 교대를 더해 주 최대 근무시간(기본 52시간)을 넘는 사람도 제외합니다. 후보 이유에 「이번 주 36시간」이 함께 보입니다. 요청 만료 시간(기본 20분), 한 교대 시간(기본 12시간), 주 최대 근무시간은 「설정」 화면에서 바꿉니다.

표에서 이름을 누르면 「결근 처리 · 빼기」, `+`를 누르면 그 라인 경험 순 추천, 제품을 누르면 바로 수정.
「비어 있음」을 누르면 요청 상태와 「다음 후보에게 · 직접 넣기」.

## 대체 후보 순위

같은 날 이미 배치된 사람과 근무 중인 조는 제외하고
`이 라인 경험×10 + 같은 제품×3 + 이 공장 경험×1 − 최근 30일 대체 횟수×25` 로 정렬합니다. (`src/lib/engine.ts`, `tests/engine.test.ts`)

## 알림

지금은 데모 모드로, 문자 대신 `/r/<토큰>` 링크를 만들어 `messages` 테이블에 저장합니다.
실제 발송은 `src/lib/repo.ts` 의 `sendMessage` 한 곳만 바꾸면 됩니다 (알림톡·SMS).
