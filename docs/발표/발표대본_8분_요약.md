# 새한프라텍 인원 배치 · 발표 대본 (8분 요약)

체험판: https://seungju-17.github.io/saehan-lineboard/ · 체험판의 오늘은 2026년 11월 10일(화) · 11월 표는 받아 둔 월 근무표로 들어 있음 · 12월 예시 파일(docs/예시)은 설정에서 올려 보여 줄 수 있음 · 시연 중 새로고침 금지

## 0. 들어가며 (1분) — 로그인 화면을 띄운 채로

- "요청하신 두 가지, 인원 자동 배치와 결원 시 대체인력 자동 통보를 실제 화면으로 보여 드립니다. 자료는 2025년 8~11월 실제 배치표입니다."
- 역할 한 줄씩: 팀장은 전부(2공장 결정·반려는 팀장만) · 지원팀 담당자는 그것만 빼고 전부 · 1·2공장 반장은 자기 공장 표 짜기와 결근 처리(2공장은 입안까지) · 근무자는 폰으로 자기 것만.
- "모든 기능을 보여 드리려고 팀장으로 들어갑니다." → [팀장 클릭]

## 1. 배치표 자동 생성 · 자동 채우기 (2분)

- 오늘 표가 차 있는 것 가리키기 → "회사에서 받은 11월 근무표를 올려 둔 겁니다. 설정 → 월 근무표 올리기에 엑셀 한 번이면 한 달 표가 들어갑니다. 받은 표가 없는 날은 같은 조의 지난 표를 복사해서 시작합니다."
- 오른쪽 근무조 카드 → "오늘 어느 조가 주간·야간·휴무인지 앱이 계산합니다."
- 제품 칸 클릭해 고치기 → 인원 +1 → 빨간 「비어 있음」 → 「자동 채우기」 → "쉬는 조에서 그 라인 경험자부터 넣습니다. 못 채운 라인은 위에 알려 줍니다."
- 「+」 눌러 후보 목록만 보여 주고 닫기 → "이름 옆에 왜 이 사람인지 이유가 붙습니다."

## 2. 결원 → 대체 요청 → 폰 수락 (2분 30초)

- 사람 2명 이상인 라인에서 이름 클릭 → 병가 → 요청 보내기 → "이 한 번으로 근태 기록, 빈 자리, 세 사람에게 요청까지 끝납니다. 쉬는 조에서 경험 순, 최근 자주 불린 사람은 뒤로, 주 52시간 넘는 사람은 뺍니다."
- 후보 이름 하나 기억 → 나가기 → 근무자에서 그 이름 → 폰 화면으로 → 요청 탭 → 수락.
- 나가기 → 팀장 → 초록 테두리 이름 확인 → "자리가 채워졌고 나머지 둘에게는 마감 알림이 갔습니다. 전화는 안 했습니다."
- 왼쪽 「대체 요청」 메뉴 → "누가 빠져서 누구에게 왜 보냈고 답이 뭐였는지 다 남습니다."

## 3. 근무자 폰 · 휴가 (1분 30초)

- 나가기 → 근무자 아무나 → 내 근무 탭 → "오늘 주·야·휴무, 내 자리, 이번 주 시간."
- 근태 탭, 달력을 11월로 → "언제 주간·야간 섰는지, 달별 시간까지 본인이 봅니다." → + 휴가 신청 → 연차, 내일 → 신청.
- 나가기 → 팀장 → 알림(빨간 1) → 승인 → "그날 표가 연차로 비고 아침에 대체 요청이 자동으로 나갑니다. 근태표에도 그대로."

## 4. 결재 · 인쇄 · 현황 (1분)

- 입안 → 결정 → "두 공장 다 반장이 입안하고 윗선이 마무리합니다. 1공장은 팀장·담당자가 확정, 2공장은 결재 양식대로 팀장만 결정. 반려하면 사유가 표 위에 뜹니다."
- 인쇄 미리보기 열고 닫기, 엑셀·월 근태표 버튼 가리키기 → "종이 양식 그대로, 월 근태표는 지금 양식 그대로 나옵니다."
- 현황 → "한 달에 빈 자리 몇 번, 대체 몇 번."

## 마무리 (30초)

- "한 달 표는 엑셀로 올려 두고, 그날 모자라면 채워 주고, 결근은 이름 한 번에 요청이 나가고, 수락한 사람이 들어갑니다."
- "실제로 쓰려면 최신 명단·전화번호, 근태 규정, 문자 계정과 서버 한 대가 필요합니다. 명단만 주시면 한 공장에서 몇 주 엑셀과 나란히 써 보는 걸 제안드립니다."
- 여쭤볼 것: 2공장 결재를 매일 실제로 하시는지, 교대 시간이 12시간이 맞는지.

## 물어보기 예시 (키가 있을 때만 시연)

- "오늘 1공장 주간 빈 자리 있어?" · "내일 야간은 어느 조가 쉬어?" · "S-4에 설 수 있는 대체 후보 알려 줘" · "11월에 결근 제일 많았던 라인은?" · "김명희 11월에 야간 며칠 섰어?"
- 한 줄: "표를 고치지는 못하고 읽기만 합니다."

## 회사에서 받으면 좋아지는 것 (질문 나올 때)

| 받을 것 | 누가 | 좋아지는 것 |
| --- | --- | --- |
| 1. 최신 직원 명단 + 전화번호 (2공장 협력사 조 포함, 엑셀 그대로) | 지원팀 | 전화번호 로그인과 실제 알림. 2공장 조 달력 일치율 상승. 퇴사자·동명이인 정리 |
| 2. 근태 규정 (주 최대 시간, 연속 근무 제한, 야간 뒤 휴식, 교대 시각·휴게) | 인사·총무 | 후보 제외 조건을 회사 규정값으로. 달별 시간이 급여 기준과 일치 |
| 3. 올해 조 편성표, 연휴 때 주기 처리 | 생산팀 | 기준일 확정, 공휴일 예외 |
| 4. 수당 배율 (야간·휴일·연장) | 인사·총무 | 후보 옆에 비용 표시, 비용 낮은 사람 먼저 |
| 5. 자격·면허와 자리별 요건 | 생산팀 | 자격 없는 사람은 후보에서 제외 |
| 6. 직책 담당자 명단 (설비관리·생산관리) | 생산팀 | 주·야 번갈아 서는 자리 자동 배치 |
| 7. 생산 계획이 오는 곳 | 생산팀 | 제품을 계획에서 받아오고 다음 주 표를 미리 |
| 8. 문자 발송 계정 + 서버 한 대 | 총무·전산 | 팀 전체가 같은 표, 알림이 실제 문자로 |
| 9. 2공장 결재를 매일 실제로 하는지 | 생산 2팀장 | 형식이면 반장 확정으로 단순화 |
| 10. 실사용 기록 | - | 추천 정확도, 결근률·대체 성공률 추이, 변경 이력 |

1·2번만 있으면 한 공장 시험 운영을 시작할 수 있다.
