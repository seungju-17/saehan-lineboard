2025년 자료(엑셀 11개)를 "숫자"가 아니라 "양식이 말해 주는 운영 방식" 기준으로 읽은 것. 라인보드가 따라가야 할 구조.

|---|---|---|

| 02. 새한 1공장 PET 2025_07, 08, 09 (xlsx) | **1공장 월 근태표 양식 + 명단**. 기록 칸은 비어 있음 | 7~9월 |
| 2공장 2025_08, 09, 10, 11, 12 (xls) | **2공장 일일 배치표**. 시트 하나가 하루 | 8/1~12/31 (약 150일) |

## 2. 1공장(생산1팀 PET) 배치표가 보여 주는 운영

**한 장에 주간·야간이 나란히.** 왼쪽 주간, 오른쪽 야간. 작성일 하나. 담당자는 하루 한 번 양쪽을 같이 짠다.

**성별 인원을 센다.** 표 맨 위에 "남자인력 n / 여자인력 n"을 교대별로 적는다. 역할이 성별과 묶여 있기 때문이다.
- 검사원(성형기 1~18호, B-1·B-2, PE-1~4) = 여성. 라인당 1명이 기본.
- BOX&운반 = 남성 2명 안팎. OP = 남성 1명. 반장 = 남성.

**구역이 넷.** PET 성형기(1~18호) · B라인(B-1, B-2) · PE라인(PE-1~4) · 지원(기타/선별&교육, BOX&운반, OP, 반장). 9월 중순부터 양식이 바뀌어 **PET와 PE가 따로** 묶이고 각각 OP와 BOX&운반을 둔다. 반장도 "주간 반장 / 야간 반장"으로 교대별 1명씩 명시.

**가동 라인만 적는다.** 18개 성형기 중 제품명이 적힌 라인만 돌아간다. 돌아가는 라인 수가 날마다 크게 다르다(8월 초 3개, 9월 중순 10개 안팎). 인원도 거기에 따라 교대당 3명에서 16명까지 움직인다. 즉 **배치표의 출발점은 생산 계획(어느 라인에 어떤 제품)**이고, 사람은 그다음이다.

**휴일은 최소 인원.** 8/9, 8/10, 8/21 같은 날은 남 0 / 여 3. 주말·공휴일에는 가동을 줄이고 몇 명만 나온다.

**결원은 "라인을 세우고 옮기는" 식으로 푼다.** 비고에 "박스인원 결원 → #13 부동 후 배치"(13호기를 세우고 그 인원을 박스로 돌림), "프리폼 기포 검수강화 인원 2명 투입". 사람을 새로 부르기보다 라인 하나를 멈추고 재배치하는 게 현장의 실제 선택지다.

**공장 간 지원이 있다.** 기타란에 "2팀지원"과 이름. 1공장 사람이 2공장에 간다.

**임시·외국인은 이름 뒤에 (여)/(남).** 바야라(여), 할로나(여), 솜야(남). 명단에 없는 사람이 와도 표에는 그냥 이름을 적는다. 여러 명은 쉼표.

**비고란은 그날의 예외를 적는 곳.** 검수 강화, 결원 대응, 특이 사항.

## 3. 2공장(생산2팀) 배치표가 보여 주는 운영

**결재 문서다.** 표 오른쪽 위에 결재란: 팀장 / 입안 / 심사·합의 / 결정. 반장(또는 생산관리)이 입안하고 팀장이 결정하는 **승인 흐름**이 양식에 박혀 있다. 1공장 양식에는 없다.

**라인 구성이 1공장과 다르다.**
- 프리폼 P-1~5호: 제품명은 늘 적혀 있는데(진로4.0, 테일러86, 올리고당, 진로투명, PCO 27) **근무자는 거의 없다**(8월 이후 한 달에 몇 칸). 프리폼 사출은 사람이 붙지 않는 자동 운전이고, 설비관리가 본다. → 제품이 있어도 "비어 있음"이 아니다.
- 성형 S-1~7호: 라인당 1명, S-7은 2명이 흔함. 제품이 자주 바뀐다.
- 선별/교육 행, 밴딩·박스·운반 2명(남성·외국인), 설비관리 1명, 생산관리 1명.

**설비관리·생산관리는 두 명이 주/야를 번갈아 선다.** 김영삼↔김경돈, 김진용↔최상진. 이 자리는 "라인"이 아니라 "직책"이고 사람이 고정이다.

**양식은 월 템플릿을 복사해 쓴다.** 09-31, 11-31 시트가 있고(없는 날짜), 19일 비고에 매달 같은 문구가 남아 있다. 한 달치 31장을 미리 만들어 두고 날마다 채우는 방식. 빈 날(주말 등)도 시트는 있다.

**반장 칸, 남/여 인원 칸은 비워 둔다.** 양식에는 있지만 쓰지 않는다.

**이름 띄어쓰기("김 옥 령")는 작성자 습관.** 같은 사람이 날에 따라 붙여 쓰기도 한다. 시스템은 이름을 정규화해야 한다.

## 4. 근태표(1공장)가 보여 주는 운영

**집단별로 시트를 나눈다.** 주전반 · 교대반 · 협력사 A조 · B조 · C조 · PE 협력사 · 지원. 이것이 실제 조직 구조다.

| 집단 | 소속 | 누구 | 배치표에서의 자리 |
|---|---|---|---|
| 주전반 | 새한 직영 | 6~7명, 조 "주전" | 주간 고정. 배치표에는 거의 안 나옴(관리·설비 쪽으로 추정) |
| 교대반 | 새한 직영 | 11~15명, A/B/C조, 남성 | 반장, OP, BOX&운반 |
| 협력사 A/B/C조 | 세영 등 | 조당 7~9명, 여성 | 검사원(성형기) |
| PE 협력사 | 협력사 | 6명 | PE-1~4 검사원 |
| 지원 | - | 명단 비어 있음 | 임시 투입 |

**한 사람당 두 줄.** 주간/야간 또는 출근/퇴근을 나눠 적는 칸으로 보인다. 맨 끝에 서명·비고.

**마감 주기가 둘이다.** 직영(주전반·교대반) 시트의 날짜는 **11일~익월 10일**, 협력사 시트는 **1일~말일**. 급여·정산 주기가 소속별로 다르다는 뜻이고, 월 집계도 둘로 나와야 한다.

**명단이 매달 바뀐다.** 교대반이 7월 11명 → 8월 15명 → 9월 14명. 입퇴사가 잦아 "직원 명단"은 월 단위로 관리되는 살아 있는 문서다.

**기록은 종이에 한다.** 파일에는 칸이 비어 있고 서명란이 있다. 출력 → 수기 → 서명 → 보관.

## 5. 운영 구조를 한 줄씩으로

1. 조직은 네 층이다. 새한 직영 남성 교대반(반장·OP·운반), 협력사 여성 검사원 조, 주간 고정 주전반, 그때그때 임시·외국인.
2. 기본 리듬은 3조 2교대지만, 표는 사람이 아니라 **라인** 기준으로 짠다. 가동 라인이 먼저, 사람은 거기에 맞춘다.
3. 하루 흐름: 전날 표 복사 → 생산 계획대로 가동 라인·제품 수정 → 조별로 사람 배치 → 남/여 집계 → (2공장) 결재 → 인쇄·게시.
4. 결원 대응은 **라인 부동 후 재배치**, **타 공장 지원**, **임시 투입** 세 가지. 전화로 사람을 찾는 것은 그다음이다.
5. 월말: 근태표 출력 → 수기 기록·서명 → 직영은 11~10일, 협력사는 1~말일로 집계.
6. 2공장 프리폼은 무인. 1공장 PE는 별도 구역.

지금 앱과 어긋나거나 빠진 것. 위부터 중요하다.

| 현장 운영 | 지금 앱 | 고칠 것 |
|---|---|---|
| 2공장 P라인은 무인, 제품만 적음 | 제품 있고 사람 없으면 빨갛게 "비어 있음" | P라인은 비어 있음 판정에서 제외(무인 라인 속성) |
| 결원 1순위는 라인 부동 후 재배치 | 결원 = 대체 요청만 | "부동" 표시와, 그 라인 인원을 다른 자리로 옮기는 동작 추가. 대체 요청은 그다음 선택지 |
| 역할이 성별과 묶임(검사원 여, 운반·OP 남), 남/여 집계 | 성별 없음 | 역할 기준 후보 추천(검사원 자리엔 검사원 경험자), 표 위에 남/여 자동 집계 |
| 1공장 PET/PE 구역, 구역별 OP·BOX·반장(주/야) | 라인 한 줄 나열 | 구역 묶음에 PE 구역과 구역별 지원 자리 반영 |
| 2공장 결재(입안→결정) | 확정 한 번 | 2공장은 "입안(반장) → 결정(팀장)" 2단계 선택 가능, 인쇄에 결재란 |
| 설비관리·생산관리는 직책, 두 사람이 주/야 교대 | 일반 자리와 같음 | 직책 자리는 고정 인원 자동 배치 |
| 공장 간 지원(2팀지원) | 없음 | 지원 보냄/받음 표기, 양쪽 표에 반영 |
| 비고란(검수 강화, 결원 대응) | 없음 | 교대별 비고 한 줄 |
| 임시·외국인 (여)/(남), 이름 띄어쓰기 | 임시로 자동 등록 | 등록 때 성별·소속 묻기, 이름 정규화 유지 |
| 명단이 집단(주전반/교대반/협력사 조/PE/지원)으로 관리, 매달 변동 | 조·근무형태만 | 집단 속성 추가, 9월 명단으로 갱신, 입퇴사 기록 |
| 근태표: 집단별 시트, 사람당 2줄, 직영 11~10일 / 협력사 1~말일, 서명란 | 없음 | 배치표에서 결근·연차 등 표시 → 월 근태표를 이 양식 그대로 출력 |
| 휴일 최소 인원 운영 | 어제 표 복사 | 주말·공휴일은 "지난 휴일 표"를 복사 기준으로 |

## 7. 아직 모르는 것 (회사에 물어볼 것)

- 근태 기호 체계(출근·연차·반차·결근·지각을 어떻게 적는지)와 연차·대체 수당 규정.
- 주전반 6~7명이 배치표에 없는 이유(관리직인지, 다른 표가 있는지).
- 2공장 명단과 근태표(2공장 협력사 조 구성).
- 생산 계획이 어디서 오는지(배치표 전에 라인·제품을 정하는 문서).
- 결재의 실제 운용(매일 서명하는지, 형식인지).
