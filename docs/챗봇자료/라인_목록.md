# 라인(자리) 목록과 구역

배치표의 한 줄이 라인 하나입니다. 1공장은 PET·PE 두 구역, 2공장은 프리폼·성형·지원·관리 네 구역입니다. 「무인」 라인은 자동 운전이라 사람을 세우지 않고 설비관리가 봅니다. 「직책」은 매 교대 한 명이 고정으로 서는 자리입니다(반장·OP·설비관리·생산관리).
